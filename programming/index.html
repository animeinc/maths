结构体、数组与指针

把一条记录的字段放在一起，写出能修改记录的函数，再看多条记录如何遍历、排序和存放。

定义一条记录

同一组读数有标签、数值和采集时间。struct Reading 定义这些成员的类型与顺序，sample 才是变量。struct Clock 也可以作为一个成员。

struct Clock {
    int hour;
    int minute;
};

struct Reading {
    char label[12];
    int value;
    struct Clock collected;
};

struct Reading sample = {"Lab-A", 20, {9, 30}};

用点号读成员。sample.value 是 20，sample.collected.minute 是 30。嵌套成员的初值用内层花括号括起来，读起来更清楚。

label 是字符数组，字符串字面量可用于初始化。之后要改内容，可逐个改字符或使用做了容量检查的复制方式；不能写 sample.label = "B"。整个结构体同类型赋值时，数组成员会随结构体一起复制。

看形参类型，判断改的是谁

传入整数成员或整条结构体，形参各自得到副本。传入 &sample 时，形参复制的是地址，通过这个地址就能修改原变量。p->value 等价于 (*p).value，括号表示先解引用。

逐步跟踪一次函数调用

查看完整 C 程序与输出 
#include <stdio.h>

struct Clock {
    int hour;
    int minute;
};

struct Reading {
    char label[12];
    int value;
    struct Clock collected;
};

struct Reading adjusted(struct Reading item)
{
    item.value += 3;
    return item;
}

void raise_value(struct Reading *item)
{
    item->value += 3;
}

int main(void)
{
    struct Reading sample = {"Lab-A", 20, {9, 30}};
    struct Reading result = adjusted(sample);
    printf("%d %d\n", sample.value, result.value);

    raise_value(&sample);
    printf("%d\n", sample.value);
    return 0;
}

第一行是 20 23，因为返回的副本存在了 result 里。第二行是 23，因为 raise_value 经由地址改了原记录。

用数组存多条记录

struct Reading readings[3] 有三条实际记录。用 readings[i].value 访问第 i 条里的数值，下标从 0 开始。

void normalize(struct Reading readings[], size_t count)
{
    for (size_t i = 0; i < count; ++i) {
        if (readings[i].value < 0) {
            readings[i].value = 0;
        }
    }
}

函数参数声明中的 readings[] 会调整成 struct Reading *readings。调用处另传条数 count。即使函数参数写成 readings[3]，sizeof readings 在函数内仍得到指针大小。

排序时可以只换指针

struct Reading *order[3] 有三个指针槽。先令 order[i] = &readings[i]，再按 order[i]->value 比较并交换指针。若原数组的数值依次为 31, 18, 25，升序的访问顺序就是 1 → 2 → 0，原数组的下标和记录对应关系保留。

查看指针选择排序的完整示例 
#include <stdio.h>

struct Reading {
    int value;
};

void sort_view(struct Reading *order[], size_t count)
{
    for (size_t i = 0; i < count; ++i) {
        size_t smallest = i;
        for (size_t j = i + 1; j < count; ++j) {
            if (order[j]->value < order[smallest]->value) {
                smallest = j;
            }
        }
        struct Reading *temp = order[i];
        order[i] = order[smallest];
        order[smallest] = temp;
    }
}

int main(void)
{
    struct Reading data[] = {{31}, {18}, {25}};
    struct Reading *order[] = {&data[0], &data[1], &data[2]};
    sort_view(order, sizeof order / sizeof order[0]);
    printf("%d %d %d\n", order[0]->value,
           order[1]->value, order[2]->value);
    printf("%d %d %d\n", data[0].value, data[1].value, data[2].value);
    return 0;
}

输出先是 18 25 31，再是 31 18 25。这段短程序只保留了排序要用的 value 字段。

算偏移和填充，再求大小

在常见的 C 内存布局中，成员按声明顺序存放。下一个成员从满足其对齐要求的位置开始，结构体末尾也可能填充，使结构体数组中的下一条记录仍满足对齐。

交换成员，观察每个字节的位置

模型假设 char 的大小与自然对齐都是 1，int 都是 4。对齐上限模拟支持 pack 的编译器。

成员偏移大小对齐

实际布局由平台 ABI 和编译器设置决定。用 sizeof 查大小、用 offsetof 查偏移，输出这两种 size_t 值用 %zu。#pragma pack 是编译器扩展，使用前看目标编译器的规则。

在本机检查默认布局 
#include <stddef.h>
#include <stdio.h>

struct Packet {
    char tag;
    int count;
    char state;
};

int main(void)
{
    printf("size=%zu align=%zu\n",
           sizeof(struct Packet), _Alignof(struct Packet));
    printf("tag=%zu count=%zu state=%zu\n",
           offsetof(struct Packet, tag), offsetof(struct Packet, count),
           offsetof(struct Packet, state));
    return 0;
}

可用 cc -std=c11 layout.c -o layout 编译，再运行 ./layout 查看你的平台结果。

自检与练习

1. adjusted(sample); 忽略返回值后，原记录的 value 是多少？

2. 交换 order[0] 与 order[1] 后，哪样东西变了？

3. 给两条成绩记录补上平均分

每条 struct Result 有 int parts[2] 和 double average。写 set_averages，在原数组上填回平均数。两条记录的分数分别是 {75, 84} 和 {88, 93}，试着先手算预期输出。

提示 1 · 找到第 i 条

读两项原始成绩用 items[i].parts[0] 与 items[i].parts[1]。

提示 2 · 让除法保留小数

用两个分数分别除以 2.0 再相加。若写成两个整数之和除以 2，小数在赋给 double 之前已被截掉。

提示 3 · 在原位置写回

形参中接收首元素指针与条数。循环从 0 到 count - 1，写入 items[i].average。

完整参考解与预期输出 
#include <stdio.h>

struct Result {
    int parts[2];
    double average;
};

void set_averages(struct Result items[], size_t count)
{
    for (size_t i = 0; i < count; ++i) {
        items[i].average = items[i].parts[0] / 2.0
                         + items[i].parts[1] / 2.0;
    }
}

int main(void)
{
    struct Result rows[] = {{{75, 84}, 0}, {{88, 93}, 0}};
    set_averages(rows, sizeof rows / sizeof rows[0]);
    printf("%.1f %.1f\n", rows[0].average, rows[1].average);
    return 0;
}

输出 79.5 90.5。测试时再用一条两项相同的记录，核对平均值等于该分数。
